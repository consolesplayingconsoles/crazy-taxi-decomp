# Crazy Taxi decomp (kick-off)

A starting point for a matching decompilation of the Dreamcast **Crazy Taxi**. It rebuilds the
game's executable byte for byte from one assembly file per function, with 430 of its 2,389
functions already named. It was generated by the `dc-decomp-kickoff` skill
([consolesplayingconsoles/skills](https://github.com/consolesplayingconsoles/skills)) as a worked
example; the decompilation itself has not started.

**This repository contains no game code or data.** You supply your own disc; `setup.sh` generates
everything game-derived on your machine, and `.gitignore` keeps it out of git.

## Supported version

| | |
|---|---|
| Release | Crazy Taxi (Europe) (En,Ja), GD-ROM, MK-51035, V1.000, 2000-01-20 |
| `1ST_READ.BIN` | 1,477,040 bytes, SHA-1 `2756d6c828b5a3848189cd84cac62bc9cb0a94b7` |
| Linked at | `0x0C010000` |
| SDK era | Shinobi 1.62, KAMUI 1.11.0.1, ADXT 5.66 |

Other releases (US, Japan) are different builds: `setup.sh` refuses them rather than produce a
broken split.

## Building

You need: your own copy of the disc as a `.gdi` (a `.chd` converts with
`chdman extractcd -i game.chd -o game.gdi`), Python 3, Docker, and a Katana SDK (its Hitachi
assembler and linker do the build).

```
./setup.sh "path/to/Crazy Taxi (Europe) (En,Ja).gdi"
SDK_PATH=path/to/katana-sdk ./build.sh
```

`build.sh` should end with `MATCH`. The first build assembles every file (a few minutes); after
that only changed files.

## What is here

| path | what |
|---|---|
| `functions.txt` | every function: address, size, name (`FUN_<addr>` = not named yet) |
| `BASE` | link address |
| `setup.sh` | extract + verify your executable, generate `asm/` and `text-map/` |
| `build.sh` | assemble, link, convert, compare with your original |
| `tools/` | disc reader, splitter, text mapper (ours) |
| `AGENTS.md` | the per-function decompilation loop |

`text-map/` (generated) lists the executable's strings with every pointer to them, the text density
of each disc file with the code that opens it, how text is drawn, and image files that probably
hold text (candidates: language variants). These are heuristics for you to check, not a verdict. Crazy Taxi draws its messages
as sprites from per-language files (`SPRMENG.BIN`, `SPRMJAP.BIN`, ...).

## Names

430 names come from signature matching: 385 from the Katana SDK's own libraries, 30 from the
public Tokyo Bus Guide decomp. Only unique matches are applied.
