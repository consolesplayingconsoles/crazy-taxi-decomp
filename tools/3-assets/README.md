# Step 3: asset mapping

| tool | what it does |
|---|---|
| [find_extras.py](find_extras.py) | The `extra` rules of a character draw function, found by running its branches per character. |
| [model_map.py](model_map.py) | Map the 3D models in a Dreamcast game's disc files and say what the executable calls them. |
| [text_dump.py](text_dump.py) | Dump the disc files a decomp lists as text, as they are. |
| [text_map.py](text_map.py) | Map where a Dreamcast game keeps its text: a starting point for translation. |
| [textures.py](textures.py) | Decode every standard Dreamcast texture on a disc to PNG and build a contact sheet. |
